# Project Azure — Discord Bot + Player Portal + PJA Host

This repository contains:

- A Discord bot using `discord.py`
- A FastAPI backend and player/manager portal
- **PJA Host V1**, a private local/VPS control dashboard
- Portable persistent data, automatic backups, restore, logs, and crash recovery

## Start here now

For the current self-hosted setup, read **`PJA-HOST-V1-GUIDE.md`**. Older Railway guides are kept only as historical update notes; Railway is no longer required by the runtime.

## Important security notice

Never commit `.env` or paste your Discord token/passwords into GitHub. PJA Host shows only whether required secrets are configured; it never displays their values in the dashboard.

## Main files to edit

| What you want to change | File or folder |
|---|---|
| Website design and wording | `website/index.html` |
| Discord slash commands | `bot/cogs/` |
| Bot startup and website-to-Discord sync | `bot/bot.py` |
| Manager role names and API helpers | `bot/utils/helpers.py` |
| Backend routes and stored data logic | `backend/main.py` |
| PJA application launcher | `start.py` |
| Private host dashboard/controller | `host/` |

## PJA Host quick start on Windows

1. Double-click `run-pja-host.bat`.
2. On the first run, it creates `.env` and opens it in Notepad.
3. Fill in the required secrets and save it.
4. Run `run-pja-host.bat` again.
5. Open `http://127.0.0.1:9100`.

The player portal still runs from the PJA backend on port `8000`. The PJA Host control panel intentionally runs on localhost only.

## Persistent storage

PJA now defaults to:

```text
data/
```

Backups default to:

```text
backups/
```

Logs default to:

```text
logs/
```

All three runtime folders are ignored by Git. You can override their locations with environment variables when the VPS is set up.
